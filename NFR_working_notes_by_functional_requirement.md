# NFR working notes by functional requirement

Working notes for the ADC requirements. This is meant to show how I got from the functional requirements to the non-functional requirements, not to be final polished wording.

## Project notes pulled from the handouts

* The ADC is a **safety-critical** software-controlled medication cabinet used in a hospital.
* Main ADC responsibilities are access control, dispensing, inventory, local event logging, fault detection, operational modes, and communication with the Monitoring System.
* The project handout explicitly says the ADC should keep operating safely when communication with the Monitoring System is temporarily unavailable.
* Deliverable 1 asks for NFRs under: safety, security, reliability, availability, performance, traceability/auditability, and usability.
* The handout also says assumptions need to be written down and requirements should be testable.

Legend: `—` means I do not think that category needs a separate NFR for that functional requirement right now.
