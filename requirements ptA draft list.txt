functional requirements draft list
• access control enforcement;
	 - Must have 2 or more forms of security measures
	 - Must have multiple mediums of security measures(physical, 		   digital, multi device etc)
	 - Must have a white and black list of users
	 - Must track previous users / attempted user logins
	 - Must have different ranks of authorization (higher rank needed 	   for more important contents)
• medication dispensing operations;
	 - Must be able to dispense medication
		 - Must have a limit for a certain time period
		 - Must dispense only if authorized user / rank / logins
		 - Must have no errors for empty case
		 - Must have no errors for full case
		 - Must dispense selected medication and amount only
		 - Must have time delay safe implementation
		 - Must dispense efficiently
		 - Must dispense without error(negligible error)

	 - Must be able to insert medication in the ADC
		 - Must have no errors for empty case
		 - Must have no errors for full case
		 - Must be able to insert efficiently
		 - Must insert without error(negligible error)


• inventory updates;
	 - Must update inventory after inserting
	 - Must have intuitive and efficient logging system
	 	- Automatic or Manual Logging system??
	 - Must take medication only, no foreign objects
	 - Must have security settings options for each medication
	 - Must have information about temperature, storage 			   conditions, etc?
	 - Must update inventory after dispensing
		 - Manually or Automatically?
	 - Must have intuitive and efficient logging system
		 - Automatic or Manual Logging system??
• local event logging;
	 - Must send activity / faults to ptB
	 - Must have internal log of ADC activity/faults
	 - Must give logs only to authorized users / rank / logins
• fault detection;
• operational modes;
• communication with external systems
